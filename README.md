# myKid GitHub Pages demo

Upload `index.html` to a new GitHub repository and enable GitHub Pages from the `main` branch and root folder.

This static demo stores data only in the browser's local storage. It includes a public Stripe purchase button, but GitHub Pages cannot verify payment or protect profiles. It is not a secure family-data application and must not be used for real financial or private child information. The secure release needs Supabase authentication/database plus a verified Stripe webhook.
